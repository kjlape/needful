macOS

Download Needful 0.15.0, open it, and drag Needful to Applications.

It isn't notarized by Apple, so the first time you open it macOS refuses. Open System Settings, then Privacy & Security, and click Open Anyway. Or, in Terminal:

xattr -dr com.apple.quarantine /Applications/Needful.app

After that it updates itself, and only installs updates signed with the key it came with.
