Any Linux, with Flatpak

flatpak install --user https://kjlape.github.io/needful/flatpak/io.github.kjlape.Needful.flatpakref

Then open Needful from your app launcher, or run flatpak run io.github.kjlape.Needful. New releases arrive with flatpak update. Version 0.15.0, for x86_64.

The command line is flatpak run io.github.kjlape.Needful <command>. The sandbox can't install services, so the phone page's service and the sync service need the Arch package, or a systemd unit of your own.
