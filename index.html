What needs doing, most needful first.

Arch Linux

Trust the key that signs the repository, once. Its fingerprint is 3396C85308E3F813688EE845B825CFDD5CE15170.

curl -fsSLO https://kjlape.github.io/needful/arch/needful.gpg
sudo pacman-key --add needful.gpg
sudo pacman-key --lsign-key 3396C85308E3F813688EE845B825CFDD5CE15170

Add the repository to /etc/pacman.conf:

[needful]
SigLevel = Required
Server = https://github.com/kjlape/needful/releases/latest/download

Then install Needful 0.15.0:

sudo pacman -Syu needful

New releases arrive with pacman -Syu. For x86_64.

A Server line ending in /arch/$arch is from before the repository moved to GitHub releases; replace it with this one.

Any Linux, with Flatpak

flatpak install --user https://kjlape.github.io/needful/flatpak/io.github.kjlape.Needful.flatpakref

Then open Needful from your app launcher, or run flatpak run io.github.kjlape.Needful. New releases arrive with flatpak update. Version 0.15.0, for x86_64.

The command line is flatpak run io.github.kjlape.Needful <command>. The sandbox can't install services, so the phone page's service and the sync service need the Arch package, or a systemd unit of your own.

macOS

Download Needful 0.15.0, open it, and drag Needful to Applications.

It isn't notarized by Apple, so the first time you open it macOS refuses. Open System Settings, then Privacy & Security, and click Open Anyway. Or, in Terminal:

xattr -dr com.apple.quarantine /Applications/Needful.app

After that it updates itself, and only installs updates signed with the key it came with.
