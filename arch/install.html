Arch Linux

Trust the key that signs the repository, once. Its fingerprint is 3396C85308E3F813688EE845B825CFDD5CE15170.

curl -fsSLO https://kjlape.github.io/needful/arch/needful.gpg
sudo pacman-key --add needful.gpg
sudo pacman-key --lsign-key 3396C85308E3F813688EE845B825CFDD5CE15170

Add the repository to /etc/pacman.conf:

[needful]
SigLevel = Required
Server = https://github.com/kjlape/needful/releases/latest/download

Then install Needful 0.15.0:

sudo pacman -Syu needful

New releases arrive with pacman -Syu. For x86_64.

A Server line ending in /arch/$arch is from before the repository moved to GitHub releases; replace it with this one.
